# Бегущая строка табло. Этот файл — образец: скопируйте его уровнем выше,
# рядом с list.txt, под именем ticker.txt и правьте там. В каталоге табло
# он лежит только для примера и никуда не подключён.
#
# Одна строка — одно объявление, поля через палку:
#
#     тип|срок|текст
#
# тип   — t обычное объявление, ! важное (выделяется красным)
# срок  — когда показывать, пусто — всегда:
#           до 10.09          по 10 сентября включительно
#           с 08.09           начиная с 8 сентября
#           с 08.09 до 12.09  окно показа
#           10.09             только в этот день
#         вместо «до» можно писать «по», год — необязателен
# текст — всё остальное до конца строки, палки внутри разрешены
#
# Пустые строки и строки с # в начале пропускаются. Строка вовсе без палок
# считается обычным объявлением целиком. Порядок в файле — порядок показа.
# Убрать объявление можно, поставив перед строкой #, — тогда оно останется
# на месте до следующего раза.
#
# Табло перечитывает файл раз в минуту, перезапускать его не нужно.
# Кодировка — UTF-8 или windows-1251, обе понимаются.

t||Расписание на завтра вывешивается после 16:00
!|до 10.09|10 сентября занятия в корпусе Б отменены
t|с 15.09 до 19.09|Неделя охраны труда: расписание на стенде у входа
